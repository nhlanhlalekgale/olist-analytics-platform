# Olist Analytics Dashboards

This directory contains production-ready dashboards for the Olist E-Commerce Analytics & ML Platform.

## Dashboard Files

### 1. **olist_churn_model_dashboard.png**
Churn Prediction Model Performance Metrics

**Contents:**
- Feature Importance (bar chart): days_since_last_order dominates at 52.2%
- ROC Curve: AUC = 0.904 (production-grade performance)
- Confusion Matrix: True Positives, False Positives, True Negatives, False Negatives
- Churn Probability Distribution: Shows separation between retained and churned customers

**Use Case**: Monitor model performance, validate feature importance, present to stakeholders

---

### 2. **olist_executive_dashboard.png**
Executive Summary - Key Metrics & Trends

**Contents:**
- Revenue Trend (2016-10 to 2018-10): R$50K → R$1.4M monthly trend
- Orders Trend + 3-Month Forecast: 2,000 → 8,000+ orders with forecast
- Average Order Value: Stable at R$161 (mean)
- Delivery Performance: On-time % trend, delivery days trend
- Customer Satisfaction (Review Score): Monthly distribution with 4.0 danger zone
- Review Submission Rate: 60%+ consistently engaged customers
- Revenue vs Delivery Speed Scatter: Bubble chart (color = review score)
- 3-Month Revenue Forecast: Sep-Nov 2018 projections
- Business Snapshot: KPIs table (revenue, orders, customers, AOV, etc.)

**Use Case**: Executive briefings, monthly performance review, forecasting accuracy checks

---

### 3. **olist_final_executive_dashboard.png**
Cohort Analysis & Geographic Performance

**Contents:**
- Cohort Retention Rates by Month: 2016-2018, segmented by Month 1, 3, 6 retention
- State Performance (Delivery vs Satisfaction): Bubble map with emoji states
- Category Satisfaction (One-Time vs Repeat Buyers): Horizontal bar chart, delist candidates highlighted
- Win-Back Segment: Dormant Customer LTV Distribution (median R$1,690, mean R$2,119)

**Use Case**: Retention strategy, geographic expansion, category prioritization, customer targeting

## How to Update Dashboards

Dashboards are generated by Python scripts in the `scripts/` directory:

```bash
# Generate all dashboards
python scripts/generate_dashboards.py

# Or generate individual dashboards
python scripts/dashboard_churn_model.py
python scripts/dashboard_executive_summary.py
python scripts/dashboard_cohort_analysis.py
```

## Viewing

1. **GitHub**: View directly in the repository
2. **Presentations**: Download and embed in Google Slides, PowerPoint, or PDF reports
3. **Automated Reports**: Referenced in `refresh_pipeline.sh` for monthly distribution
